接続設定

Apps Script の「デプロイ → ウェブアプリ」で表示される、/exec で終わる URL。

スプレッドシートのメニュー「紹介者管理 → 外部連携用の合言葉を発行」で作れます。

URL と合言葉はこの端末のブラウザ（localStorage）に保存されます。共有端末では使い終わったら「接続を解除」してください。
