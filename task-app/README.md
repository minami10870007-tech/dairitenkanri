# めっちゃ簡単なタスク管理アプリ（スプレッドシート + GAS）

スプレッドシートの「タスク」シートをデータベースにした、最小限のタスク管理です。

できること：**追加（期限つき可） / 完了チェック / 削除 / 一覧**（未完了→期限が近い順。期限切れは赤字）

## セットアップ（5分）

1. 新しい Google スプレッドシートを作る
2. メニュー **拡張機能 → Apps Script** を開く
3. 最初からある `コード.gs` の中身を全部消して、[`Code.gs`](Code.gs) の中身を貼り付ける
4. 左の「＋」→ **HTML** で `index` という名前のファイルを作り、[`index.html`](index.html) の中身を貼り付ける
   （名前は `index` だけ。`.html` は自動で付きます）
5. 保存（Ctrl+S）してスプレッドシートを再読み込み
6. メニューに **タスク管理 → アプリを開く** が出るのでクリック
   - 初回だけ「承認が必要です」と出るので、自分のアカウントを選んで許可
     （「このアプリは確認されていません」→「詳細」→「（安全でないページ）に移動」）

「タスク」シートは初回に自動で作られます。シートを直接編集しても OK です。

## スマホからも使いたい場合（任意）

Apps Script 画面の **デプロイ → 新しいデプロイ → 種類: ウェブアプリ** で
「次のユーザーとして実行: 自分」「アクセスできるユーザー: 自分のみ」にしてデプロイ。
発行された URL をスマホのブラウザで開けば同じ画面が使えます。

※ コードを変更したら「デプロイを管理 → 編集 → 新バージョン」で更新しないと URL 側には反映されません。
