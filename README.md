# 紹介者管理アプリ（スプレッドシート + GAS）

Google スプレッドシートを保存先にして、紹介者と紹介案件を管理するシンプルなアプリです。
サーバーもデータベースも不要で、スプレッドシート1つと Google Apps Script だけで動きます。

## できること

- 紹介者の登録（紹介者名・電話番号・メール・被紹介者・ステータス・備考）
- 一覧表示とキーワード検索（紹介者名 / 被紹介者 / 電話 / メール / 備考 / ID の部分一致）
- ステータスの絞り込みと、一覧上でのステータス変更（未対応 / 対応中 / 成約 / 見送り）
- 1件削除
- 集計（合計件数、ステータス別件数、紹介者ごとの紹介件数・成約数）

データは「紹介者」シートに1件=1行で入るので、スプレッドシート側で直接編集・並べ替え・
フィルタ・ピボットテーブルを使うこともできます。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `src/Code.gs` | サーバー側（シート読み書き・検索・集計・メニュー・ウェブアプリの入り口） |
| `src/index.html` | 画面（新規登録 / 一覧・検索 / 集計の3タブ） |
| `src/appsscript.json` | Apps Script のマニフェスト（タイムゾーンと公開設定） |
| `test/smoke.js` | サーバー側ロジックのテスト（Node で実行） |
| `test/gas-stub.js` | テスト用に GAS の API を最小限だけ模したスタブ |

## セットアップ（コピペでOK・5分）

1. Google スプレッドシートを新規作成する。
2. メニューの **拡張機能 → Apps Script** を開く。
3. 既定の `コード.gs` の中身を全部消して、`src/Code.gs` の内容を貼り付ける。
4. 左の **ファイル → ＋ → HTML** で `index` という名前のファイルを作り、`src/index.html` の内容を貼り付ける
   （ファイル名は拡張子なしの `index` にする。`doGet` / `openApp` がこの名前で読み込みます）。
5. 保存して、関数一覧から `setup` を選んで **実行**。初回は権限の承認を求められるので許可する。
   → スプレッドシートに「紹介者」シートが作られ、見出し行とステータスのプルダウンが設定される。
6. スプレッドシートを再読み込みすると、メニューに **紹介者管理** が出る。
   **紹介者管理 → アプリを開く** で画面が開きます。

※ `src/appsscript.json` の内容を反映したい場合は、Apps Script エディタの
**プロジェクトの設定 → 「appsscript.json」マニフェスト ファイルをエディタで表示する** を
オンにしてから貼り付けてください（タイムゾーンが `Asia/Tokyo` になります）。

### スマホやブラウザから使いたい場合（任意）

Apps Script エディタで **デプロイ → 新しいデプロイ → 種類：ウェブアプリ** を選び、

- 次のユーザーとして実行：**自分**
- アクセスできるユーザー：**自分のみ**（社内メンバーにも使わせるなら組織内、
  誰でも使わせるなら「全員」。「全員」は URL を知っている人が誰でも書き込めるので注意）

でデプロイすると、発行された URL からスマホでも同じ画面が使えます。

### clasp を使う場合

```bash
npm install -g @google/clasp
clasp login
cd src
clasp create --type sheets --title "紹介者管理"   # 既存シートに紐づけるなら clasp clone <scriptId>
clasp push
```

## テスト

サーバー側のロジック（登録・検索・更新・削除・集計・ID採番）は、GAS の API をスタブに
置き換えて Node で実行できます。

```bash
node test/smoke.js
```

## データの列

| 列 | 説明 |
| --- | --- |
| ID | `R0001` 形式の自動採番。既存の最大値 + 1 なので削除しても重複しない |
| 登録日 | 登録した日時 |
| 紹介者名 | 必須項目 |
| 電話番号 / メール | 任意 |
| 被紹介者 | 紹介された人・会社 |
| ステータス | 未対応 / 対応中 / 成約 / 見送り |
| 備考 | 経緯やメモ |
| 更新日 | 最後に更新した日時 |

## カスタマイズのヒント

- 項目を増やす → `src/Code.gs` の `HEADERS` に列名を追記し、`src/index.html` の入力欄と
  一覧のカラムを同じ列名で追加する（サーバー側は `HEADERS` を見て動くので、追加した項目は
  検索対象にしたい場合のみ `listReferrers` の検索キー配列にも足す）。
- ステータスの選択肢を変える → `src/Code.gs` の `STATUSES` を書き換えて `setup` を再実行する。
- 紹介料や成約金額を管理したい → `HEADERS` に「金額」を追加し、`getSummary` で合計すると
  紹介者ごとの実績が出せます。
